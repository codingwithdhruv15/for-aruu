# Proposal Website 💖

Files: page-1 .. page-4 (har ek ka .html, .css, .js) + index.html (page-1 pe bhejta hai) + media/ folder.

## Text badalna
Har page-N.js ke sabse upar `CONFIG` hai. Wahin apne notes/letter likho.
- page-1.js : pehla note
- page-2.js : doosra note + photos/videos ki list (MEDIA)
- page-3.js : letter
- page-4.js : proposal

## Photos / Videos (page 2)
1. Files `media/` folder me daalo.
2. `page-2.js` me `MEDIA` list me naam likho, e.g. "photo1.jpg", "video1.mp4".

## GitHub Pages pe hamesha online
1. github.com pe naya public repository banao (e.g. `for-you`).
2. Is folder ki saari files (index.html, page-*.*, media/) upload karo.
3. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/for-you/
